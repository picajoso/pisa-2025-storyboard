# PISA 2025 Interactive Data Storyboard

## Tech Stack
- Framework: Vite + React + TypeScript + Tailwind CSS (v3 o v4)
- Components & Icons: Lucide React, Shadcn/ui patterns
- Charts: Recharts
- Animations: Framer Motion
- Quality Checks: Run `npm run build` and `npm run lint` before completing tasks.

## Design Philosophy (Data Journalism / Scrollytelling)
- Aesthetic: Modern, high-end editorial (similar to The Pudding, NYT Graphics, or Financial Times).
- Palette: Slate/Zinc dark background (`bg-slate-950`), subtle borders (`border-slate-800`), refined data accents (cyan/teal for positive/leaders, amber/rose for declines and gaps).
- Layout: Scrollytelling format with high-impact hero metrics, dynamic charts, toggle filters (Science, Math, Reading), and interactive cards for takeaways (AI debate, school belonging, screen distractions).
